# Keyboard

This page is generated by `cargo xtask keyboard` from the command catalog, the keymap's defaults and the key tables. Do not edit it by hand; change the catalog or the tables instead.

Each line gives the key first, then the command, what it does, and its id in parentheses. A key is one key with its modifiers; there are no key sequences. Insert is never used, because it is the screen readers' key. Change any key in `keymap.toml` in the config folder; diroxide writes the built-in keys beside it as `keymap-defaults.toml`. The `single_letters` setting turns keys without Control or Alt off.

The command palette reaches every command by name: Ctrl+P in a terminal, Ctrl+Shift+P or Ctrl+P in the window. The menus are the sure way where a terminal does not pass a key: F9, or Alt with a menu's letter.

## In a terminal

### Everywhere

- Ctrl+Q: Quit. Leaves diroxide. (app.quit)
- Shift+F1 or ?: Help. Says help for where the focus is. (app.help)
- Ctrl+D: Say status. Says the panel, the count, the selection, the focus and any job's progress. (app.say-status)
- Alt+O: Say other panel. Says the other panel's place and its focused row. (app.say-other)
- Ctrl+P: Command palette. Finds any command by name and runs it. (app.palette)
- F9: Menus. Opens the menu bar. (app.menu)
- Escape: Cancel. Closes the menu or dialog, or stops the job in front. (app.cancel)
- Ctrl+Z: Undo. Reverses the last job: a rename, move, copy, new folder or trashing. (edit.undo)
- Alt+F: File menu. Opens the File menu. (menu.file)
- Alt+E: Edit menu. Opens the Edit menu. (menu.edit)
- Alt+V: View menu. Opens the View menu. (menu.view)
- Alt+G: Go menu. Opens the Go menu. (menu.go)
- Alt+S: Select menu. Opens the Select menu. (menu.select)
- Alt+T: Tools menu. Opens the Tools menu. (menu.tools)
- Alt+P: Plugins menu. Opens the Plugins menu. (menu.plugins)
- Alt+H: Help menu. Opens the Help menu. (menu.help)

### In a panel

- Tab: Switch panels. Makes the other panel active. (panel.switch)
- Ctrl+U: Swap panels. Swaps the places the two panels show. (panel.swap)
- Ctrl+Right: Folder to other panel. Shows the focused folder in the other panel. (panel.show-in-other)
- Ctrl+Left: This folder to other panel. Shows this folder in the other panel too. (panel.this-in-other)
- Enter: Open. Opens the focused folder, archive or file. (panel.enter)
- Right: Into folder. Enters the focused folder or archive; on a file, says its kind. (panel.into)
- Left or Backspace or Alt+Up: Up one folder. Goes to the folder above, with the cursor on the folder just left. (panel.up)
- Ctrl+R: Reload. Lists the folder again. (panel.reload)
- Alt+Left: Back. Goes to the folder before this one, with its cursor and marks. (go.back)
- Alt+Right: Forward. Goes forward again after Back. (go.forward)
- Alt+Home: Home folder. Goes to your home folder. (go.home)
- Ctrl+L or Alt+D: Go to a path. Asks for a path and goes there, completing names as you type. (go.path)
- Ctrl+G: Go to a place. Lists the drives, home and the places you use most. (go.places)
- Space: Select or unselect. Selects or unselects the focused row and moves down. (select.toggle)
- Ctrl+A: Select all. Selects every row. (select.all)
- *: Invert selection. Selects what was not selected, and the reverse. (select.invert)
- Plus: Select by pattern. Selects the rows whose names match a pattern; it starts as a star, which selects all. (select.pattern)
- Minus: Unselect by pattern. Unselects the rows whose names match a pattern. (select.unpattern)
- Ctrl+Down: Next selected. Moves to the next selected row. (select.next)
- Ctrl+Up: Previous selected. Moves to the previous selected row. (select.previous)
- F3: View. Opens the focused file in the viewer. (file.view)
- F4: Edit. Opens the focused file in your editor, then comes back. (file.edit)
- F5: Copy to other panel. Copies the selection to the other panel's folder. (file.copy)
- F6: Move to other panel. Moves the selection to the other panel's folder, after listing it. (file.move)
- F7: Make folder. Asks for a name and makes a folder here. (folder.make)
- F8 or Delete: Move to trash. Moves the selection to the trash, after listing it. (file.trash)
- Shift+Delete: Delete for good. Deletes the selection for good after listing every path; it cannot be undone. (file.delete-permanently)
- F2: Rename. Asks for a new name; with several selected, steps through them. (file.rename)
- Shift+F5: Duplicate. Copies the selection into this folder under new names. (file.duplicate)
- Alt+Enter: Details. Says everything known about the focused entry. (file.details)
- Shift+F10 or Menu: Context menu. Lists what can be done with the focused entry or the selection. (file.context-menu)
- Ctrl+C: Copy. Puts the selection on the file clipboard, to paste elsewhere. (clipboard.copy)
- Ctrl+X: Cut. Puts the selection on the file clipboard, to move when pasted. (clipboard.cut)
- Ctrl+V: Paste. Copies or moves what is on the file clipboard into this folder. (clipboard.paste)
- Alt+Period: Show hidden files. Shows or hides hidden files and folders. (view.hidden)
- Ctrl+S: Filter. Shows only the names that match what you type; Cancel or Clear filter ends it. (view.filter)
- Ctrl+F3: Sort by name. Sorts by name, A to Z; again for Z to A. (view.sort-name)
- Ctrl+F4: Sort by extension. Sorts by extension, A to Z; again for Z to A. (view.sort-extension)
- Ctrl+F5: Sort by modified. Sorts by modified time, newest first; again for oldest first. (view.sort-modified)
- Ctrl+F6: Sort by size. Sorts by size, largest first; again for smallest first. (view.sort-size)
- Ctrl+F7: Unsorted. Lists in the folder's own order. (view.sort-unsorted)

- Sort by owner. Sorts by owner, A to Z; again for Z to A. (view.sort-owner)
- Sort by label. Sorts by label, A to Z; again for Z to A. (view.sort-label)
- Sort list. Lists every sort key, the current one marked with its direction. (view.sort-list)
- Plugins. Lists the plugins and what they may do. Plugins come with alpha.4. (plugins.list)

## Keys a terminal may keep

These keys of the terminal list work in most terminals, but a terminal program may keep them or send another key. Each one's command is also in a menu, the sure way.

- Ctrl+Q for Quit: The Claude app's terminal keeps it; it takes the key for itself, so the key never arrives; the palette's Quit and the F9 menus are the way. Sure way: File menu, Quit.
- Shift+F1 for Help: Some terminals send Shift with F1 to F12 as F13 to F24. Sure way: Help menu, Help.
- Alt+F for File menu: The Claude app's terminal keeps it; it takes the key for itself, so the key never arrives; the palette's Quit and the F9 menus are the way. Sure way: the command palette.
- Ctrl+Right for Folder to other panel: macOS keeps it; Mission Control uses Control with the arrows. Sure way: Go menu, Folder to other panel.
- Ctrl+Left for This folder to other panel: macOS keeps it; Mission Control uses Control with the arrows. Sure way: Go menu, This folder to other panel.
- Alt+Up for Up one folder: Windows Terminal keeps it; it moves between panes when the window has panes. Sure way: Go menu, Up one folder.
- Alt+Left for Back: Windows Terminal keeps it; it moves between panes when the window has panes. Sure way: Go menu, Back.
- Alt+Right for Forward: Windows Terminal keeps it; it moves between panes when the window has panes. Sure way: Go menu, Forward.
- Ctrl+Down for Next selected: macOS keeps it; Mission Control uses Control with the arrows. Sure way: Select menu, Next selected.
- Ctrl+Up for Previous selected: macOS keeps it; Mission Control uses Control with the arrows. Sure way: Select menu, Previous selected.
- Shift+F5 for Duplicate: Some terminals send Shift with F1 to F12 as F13 to F24. Sure way: File menu, Duplicate.
- Alt+Enter for Details: Windows Terminal keeps it; it goes full screen. Sure way: File menu, Details.
- Shift+F10 for Context menu: Some terminals send Shift with F1 to F12 as F13 to F24. Sure way: File menu, Context menu.
- Ctrl+C for Copy: Windows Terminal keeps it; it copies text when text is selected. Sure way: Edit menu, Copy.
- Ctrl+V for Paste: Windows Terminal keeps it; it pastes text, so the key never arrives. Sure way: Edit menu, Paste.
- Ctrl+F3 for Sort by name: macOS keeps it; the system uses Ctrl+F3 to Ctrl+F8 for the Dock, the menu bar and windows. Sure way: View menu, Sort submenu, Sort by name.
- Ctrl+F4 for Sort by extension: macOS keeps it; the system uses Ctrl+F3 to Ctrl+F8 for the Dock, the menu bar and windows. Sure way: View menu, Sort submenu, Sort by extension.
- Ctrl+F5 for Sort by modified: macOS keeps it; the system uses Ctrl+F3 to Ctrl+F8 for the Dock, the menu bar and windows. Sure way: View menu, Sort submenu, Sort by modified.
- Ctrl+F6 for Sort by size: macOS keeps it; the system uses Ctrl+F3 to Ctrl+F8 for the Dock, the menu bar and windows. Sure way: View menu, Sort submenu, Sort by size.
- Ctrl+F7 for Unsorted: macOS keeps it; the system uses Ctrl+F3 to Ctrl+F8 for the Dock, the menu bar and windows. Sure way: View menu, Sort submenu, Unsorted.

## Keys never used in a terminal

- Insert, with any key held: Insert is the screen reader key.
- The keypad's Plus, Minus, Star and Slash: terminals send the keypad's keys as the main row's characters.
- Ctrl+I: terminals send it as Tab.
- Ctrl+M: terminals send it as Enter.
- Ctrl+H: some terminals send it as Backspace.
- Ctrl+J: terminals send it as a line feed, which many use for Ctrl+Enter.
- Ctrl+[: terminals send it as Escape.
- Ctrl+Space: Unix terminals send it as a null character, and input methods take it.
- Ctrl+Enter: terminals send it as Enter or a line feed.
- Shift+Enter: terminals send it as Enter.
- Ctrl+Tab, Ctrl+Shift+Tab: terminals send it as Tab, and Windows Terminal switches tabs on it.
- Ctrl+Shift with a letter: terminals send it as Control and the letter, and Windows Terminal keeps several.
- F1: GNOME Terminal opens its help on it.
- F10: GNOME Terminal opens its menu on it.
- F11: Windows Terminal and GNOME Terminal go full screen on it.
- F12: it is kept free for the terminal programs, as the plan decided.
- Alt with a digit: GNOME Terminal switches tabs on Alt and a digit.
- Ctrl+Page Up, Ctrl+Page Down: GNOME Terminal switches tabs on it.
- Ctrl+Backspace: many terminals send it as Ctrl+H or as Backspace.

## Keys the screen readers keep

diroxide binds none of these. A keypad key works under a screen reader only with Num Lock on, so it is never a command's only key.

- Insert, with any key held: NVDA, JAWS, Orca and Narrator, as their modifier key.
- Ctrl+Alt+N: NVDA, to start NVDA.
- Ctrl+Alt+J: JAWS, to start JAWS.
- Ctrl+Alt+S: Some screen reader setups, for their own commands.
- Ctrl+Alt+Left, Ctrl+Alt+Right, Ctrl+Alt+Up, Ctrl+Alt+Down: NVDA, JAWS and Narrator, to move between table cells.
- Ctrl+Alt+Home, Ctrl+Alt+End: JAWS, to go to the first or last table cell.
- Win+Alt+Left, Win+Alt+Right, Win+Alt+Up, Win+Alt+Down: JAWS, to move by table rows and columns.
- The keypad's Plus, Minus, Star and Slash: NVDA, JAWS and Orca, to review text when Num Lock is off.
- Ctrl+Win+Enter: Narrator, to start and stop Narrator.
- Cmd+F5: VoiceOver, to turn VoiceOver on and off. On macOS.
- Ctrl+Option with any key: VoiceOver, as its modifier, Control and Option. On macOS.
- Super+Alt+S: Orca, to turn Orca on and off in GNOME. On Linux.
