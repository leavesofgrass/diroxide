Quick start
===========

Install diro, then open a folder. The `install guide <https://example.org/install>`_
says more.

Moving around
-------------

- Up and Down move the cursor.
- Tab switches panels.
- Enter opens a folder.

Keys
----

=====  ==========
Key    Does
=====  ==========
F3     View
F5     Copy
F6     Move
=====  ==========

See the `key list <https://example.org/keys>`_ for the rest.
