# Keyboard: the vim-style preset

This page is generated by `cargo xtask keyboard` from `crates/diroxide-app/keys/presets/vim-style.toml`. Do not edit it by hand; change the preset file instead.

For people who want h, j, k and l: single letters run commands, as in ranger, lf, yazi and vifm.

Choose it in the Keys list (its first row, Choose a preset), with Key presets in the palette or in the Tools menu's Keys submenu, or from a shell with `diro keys preset vim-style`. Your own keys in `keymap.toml` stay on top of it, and every key it does not list is the one on [the keyboard page](keyboard.md). Each line below gives the key first, then the command, the key it replaces, and the command's id.

Single letters run commands with this preset: typing no longer jumps to names, and the slash opens the filter. Choosing it turns type-ahead off; choosing another preset turns it back on.

Its keys come from the manual pages of ranger and vifm, lf's documentation and yazi's quick start.

## Held back

These keys of the source are two keys in a row, which diroxide does not use: a key here is one key with its modifiers. The command each would run is reached by its own key, the menus or the palette.

- G G: First row, as g here.
- D D: Move to trash, as d here.
- Y Y: Copy, as y here.
- P P: Paste, as p here.
- C W: Rename, as r here.
- Z H: Show hidden files, as the period here.
- G T: Next tab, with alpha.8.
