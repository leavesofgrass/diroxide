# Keyboard

This page is generated by `cargo xtask keyboard` from the command catalog, the keymap's defaults and the key tables. Do not edit it by hand; change the catalog or the tables instead.

Each line gives the key first, then the command, what it does, and its id in parentheses. A key is one key with its modifiers; there are no key sequences. Insert is never used, because it is the screen readers' key. Change any key in `keymap.toml` in the config folder; diroxide writes the built-in keys beside it as `keymap-defaults.toml`. The `single_letters` setting turns keys without Control or Alt off.

The command palette reaches every command by name: Ctrl+P in a terminal, Ctrl+Shift+P or Ctrl+P in the graphical interface (GUI). The menus are the sure way where a terminal does not pass a key: F9, or Alt with a menu's letter.

## In a terminal

### Everywhere

- Ctrl+Q: Quit. Leaves diroxide. (app.quit)
- Shift+F1 or ?: Help. Says help for where the focus is. (app.help)
- Ctrl+D: Say status. Says the panel, the count, the selection, the focus and any job's progress. (app.say-status)
- Alt+O: Say other panel. Says the other panel's place and its focused row. (app.say-other)
- Ctrl+P: Command palette. Finds any command by name and runs it. (app.palette)
- F9: Menus. Opens the menu bar. (app.menu)
- Escape: Cancel. Closes the menu or dialog, stops the job in front or the search, or else stops watching the folder or takes the filter off. (app.cancel)
- Ctrl+Z: Undo. Reverses the last job: a rename, move, copy, new folder or trashing. (edit.undo)
- Alt+F: File menu. Opens the File menu. (menu.file)
- Alt+E: Edit menu. Opens the Edit menu. (menu.edit)
- Alt+V: View menu. Opens the View menu. (menu.view)
- Alt+G: Go menu. Opens the Go menu. (menu.go)
- Alt+S: Select menu. Opens the Select menu. (menu.select)
- Alt+T: Tools menu. Opens the Tools menu. (menu.tools)
- Alt+P: Plugins menu. Opens the Plugins menu. (menu.plugins)
- Alt+H: Help menu. Opens the Help menu. (menu.help)
- Shift+F3: Quick view. Turns the other panel into a live preview of the file under the cursor, or back to its files. (view.quick-view)

### In a panel

- Tab: Switch panels. Makes the other panel active. (panel.switch)
- Ctrl+U: Swap panels. Swaps the places the two panels show. (panel.swap)
- Ctrl+Right: Folder to other panel. Shows the focused folder in the other panel. (panel.show-in-other)
- Ctrl+Left: This folder to other panel. Shows this folder in the other panel too. (panel.this-in-other)
- Enter: Open. Opens the focused folder, archive or file. (panel.enter)

- Left or Backspace or Alt+Up: Up one folder. Goes to the folder above, with the cursor on the folder just left. (panel.up)
- Ctrl+R: Reload. Lists the folder again. (panel.reload)
- Alt+Left: Back. Goes to the folder before this one, with its cursor and marks. (go.back)
- Alt+Right: Forward. Goes forward again after Back. (go.forward)
- Alt+Home: Home folder. Goes to your home folder. (go.home)
- Ctrl+L or Alt+D: Go to a path. Asks for a path and goes there, completing names as you type. (go.path)
- Ctrl+G: Go to a place. Lists the drives, home and the places you use most. (go.places)
- Space: Select or unselect. Selects or unselects the focused row and moves down. (select.toggle)
- Ctrl+A: Select all. Selects every row. (select.all)
- *: Invert selection. Selects what was not selected, and the reverse. (select.invert)
- Plus: Select by pattern. Selects the rows whose names match a pattern; it starts as a star, which selects all. (select.pattern)
- Minus: Unselect by pattern. Unselects the rows whose names match a pattern. (select.unpattern)
- Ctrl+Down: Next selected. Moves to the next selected row. (select.next)
- Ctrl+Up: Previous selected. Moves to the previous selected row. (select.previous)
- F3: View. Opens the focused file in the viewer. (file.view)
- F4: Edit. Opens the focused file in your editor, then comes back. (file.edit)
- F5: Copy to other panel. Copies the selection to the other panel's folder. (file.copy)
- F6: Move to other panel. Moves the selection to the other panel's folder, after listing it. (file.move)
- F7: Make folder. Asks for a name and makes a folder here. (folder.make)
- F8 or Delete: Move to trash. Moves the selection to the trash, after listing it. (file.trash)
- Shift+Delete: Delete for good. Deletes the selection for good after listing every path; it cannot be undone. (file.delete-permanently)
- F2: Rename. Asks for a new name; with several selected, steps through them. (file.rename)
- Shift+F5: Duplicate. Copies the selection into this folder under new names. (file.duplicate)
- Alt+Enter: Details. Says everything known about the focused entry. (file.details)
- Shift+F10 or Menu: Context menu. Lists what can be done with the focused entry or the selection. (file.context-menu)
- Ctrl+C: Copy. Puts the selection on the file clipboard, to paste elsewhere. (clipboard.copy)
- Ctrl+X: Cut. Puts the selection on the file clipboard, to move when pasted. (clipboard.cut)
- Ctrl+V: Paste. Copies or moves what is on the file clipboard into this folder. (clipboard.paste)
- Alt+Period: Show hidden files. Shows or hides hidden files and folders. (view.hidden)
- Ctrl+S: Filter. Shows only what matches what you type, in the filter language, such as size over 1 MB; Cancel or Clear filter ends it. (view.filter)
- Ctrl+F3: Sort by name. Sorts by name, A to Z; again for Z to A. (view.sort-name)
- Ctrl+F4: Sort by extension. Sorts by extension, A to Z; again for Z to A. (view.sort-extension)
- Ctrl+F5: Sort by modified. Sorts by modified time, newest first; again for oldest first. (view.sort-modified)
- Ctrl+F6: Sort by size. Sorts by size, largest first; again for smallest first. (view.sort-size)
- Ctrl+F7: Unsorted. Lists in the folder's own order. (view.sort-unsorted)
- Ctrl+F: Find files. Searches names and contents below this folder or the marked items, the results listed as they are found. (search.find)
- Alt+L: Set label. Adds a label to the marked items, or the focused one; a new name makes a new label. (label.set)

- Ctrl+7: Favorite label 7. Adds the seventh label of the Labels list to the marked items, or takes it off when every one has it. (label.favorite-7)
- Ctrl+B or Alt+B: Bookmarks. Lists the bookmarks; the first row adds or removes this folder, and an alias letter jumps. (go.bookmarks)

### In the viewer

- Left: Previous token. Moves to the token before, or the byte before in hex mode, and says it. (viewer.left)

- W: Wrap lines. Wraps long lines at the screen's width, or stops wrapping. (viewer.wrap)
- L: Line numbers. Shows or hides the number of each line. (viewer.line-numbers)
- G or Ctrl+G: Go to line. Asks for a line, an offset or a percent, and goes there. (viewer.jump)
- / or F7: Search in file. Asks for text, quoted text or hex bytes, and finds it after the cursor. (viewer.search)
- ?: Search backward. Asks for text and finds it before the cursor. (viewer.search-back)
- N: Next match. Goes to the next match of the last search. (viewer.next-match)
- P: Previous match. Goes to the match before, of the last search. (viewer.previous-match)
- H: Hex mode. Switches between the text and rows of bytes. (viewer.hex)
- B: Say byte. Says the byte at the cursor in hex and as a character. (viewer.byte)
- Shift+R: Read more. Reads further into a file larger than the viewer keeps. (viewer.read-more)
- Ctrl+R: Reload file. Reads the file again from its place. (viewer.reload)
- F: Follow file. Goes to the end and stays there as the file grows, or stops. (viewer.follow)
- Alt+N: Next file. Shows the next file of the folder in the viewer. (viewer.next-file)
- Alt+P: Previous file. Shows the file before in the viewer. (viewer.previous-file)
- K: Say token kind. Says what the token at the cursor is, such as a keyword or a function name. (viewer.token-kind)
- Shift+K: Say line by kind. Says the kinds of token on the cursor's line, in order. (viewer.line-kinds)
- O: Outline. Lists the file's symbols, to go to one. (viewer.outline)
- S: Next symbol. Goes to the next function, type or heading. (viewer.next-symbol)
- Shift+S: Previous symbol. Goes to the function, type or heading before. (viewer.previous-symbol)
- M: Matching bracket. Goes to the bracket that matches the one at the cursor. (viewer.bracket)
- C: Skip comment. Goes to the next line of code after a comment. (viewer.skip-comment)
- I: Say indent. Says the indent level of the cursor's line. (viewer.indent)
- X: Say context. Says the function and the blocks the cursor is in. (viewer.context)

- Shift+T: Previous table. Goes to the table above, its rows and columns said. (preview.previous-table)
- Left: Cell to the left. In a table, the cell to the left, said with its header. (preview.cell-left)

- Ctrl+L: Previous link. Goes to the link before, said with where it goes. (preview.previous-link)

- P: Previous match in the preview. Goes to the match before, of the last find in the preview. (preview.previous-match)
- Alt+N: Next file in the preview. Shows the panel's next file in the preview without leaving it; the panel's cursor follows. (preview.next-file)
- Alt+P: Previous file in the preview. Shows the panel's file before in the preview without leaving it; the panel's cursor follows. (preview.previous-file)

- Insert, with any key held: NVDA, JAWS, Orca and Narrator, as their modifier key.

- Ctrl+Alt+J: JAWS, to start JAWS.
