# Keyboard

This page is generated by `cargo xtask keyboard` from the keymap's defaults. Do not edit it by hand; change the command catalog or the keymap instead.

Each line gives the key first, then the command and what it does. Every key is one key with its modifiers; there are no key sequences. Insert is never used, because it is the NVDA and JAWS key. Keys can be changed in `keymap.toml`, and single-letter keys can be turned off.

## Everywhere

- Ctrl+Q or F10: Quit. Leaves diroxide.
- F1: Help. Says help for where the focus is.
- Ctrl+Shift+S: Say status. Says the panel, the count, the selection and the focus.
- Ctrl+P: Command palette. Finds any command by name.
- F9: Menus. Opens the menu bar.
- Ctrl+L: Go to a path. Asks for a path and goes there.
- Ctrl+Z: Undo. Reverses the last job's renames, moves and trashings.

## In a panel

- Tab: Switch panels. Makes the other panel active.
- Enter: Open. Opens the focused folder, archive or file.
- Backspace: Up one folder. Goes to the folder above.
- Ctrl+R: Reload. Lists the folder again.
- Space: Select or unselect. Selects or unselects the focused row and moves down.
- Keypad Plus or Ctrl+A: Select all. Selects every row.
- Keypad Minus or Ctrl+Shift+A: Select none. Clears the selection.
- Keypad Star or Ctrl+I: Invert selection. Selects what was not selected, and the reverse.
- Keypad Slash or Ctrl+Shift+P: Select by pattern. Selects the rows whose names match a pattern.
- F3: View. Opens the focused file in the viewer.
- F4: Edit. Opens the focused file in the editor.
- F5: Copy to other panel. Copies the selection to the other panel's folder.
- F6: Move to other panel. Moves the selection to the other panel's folder, after listing it.
- F7: Make folder. Asks for a name and makes a folder.
- F8 or Delete: Move to trash. Moves the selection to the trash, after listing it.
- Shift+Delete: Delete permanently. Deletes the selection for good, after listing every path.
- F2: Rename. Asks for a new name for the focused entry.
- Ctrl+H: Show or hide hidden files. Shows or hides hidden entries.
- Alt+F7: Find files. Searches by name and content.

## In any list

- Up: Previous row. Moves the focus up one row.
- Down: Next row. Moves the focus down one row.
- Page Up: Previous page. Moves the focus up one page.
- Page Down: Next page. Moves the focus down one page.
- Home: First row. Moves the focus to the first row.
- End: Last row. Moves the focus to the last row.
