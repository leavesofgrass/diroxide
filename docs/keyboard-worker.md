# Keyboard: the Worker preset

This page is generated by `cargo xtask keyboard` from `crates/diroxide-app/keys/presets/worker.toml`. Do not edit it by hand; change the preset file instead.

For people who know Worker's keys: the keypad selects, Backspace goes back, Alt+N and Alt+T sort.

Choose it in the Keys list (its first row, Choose a preset), with Key presets in the palette or in the Tools menu's Keys submenu, or from a shell with `diro keys preset worker`. Your own keys in `keymap.toml` stay on top of it, and every key it does not list is the one on [the keyboard page](keyboard.md). Each line below gives the key first, then the command, the key it replaces, and the command's id.

Single letters still jump to names with this preset.

Its keys come from the project's survey of Worker's features, its key bindings, never Worker's own files.

## In a terminal

### Everywhere

- Ctrl+Q or Alt+Q: Quit. Was Ctrl+Q. (app.quit)

### In a panel

- Ctrl+A or Plus: Select all. Was Ctrl+A. (select.all)
- Minus: Select none. No key before. (select.none)
- No key: Select by pattern. Was Plus. (select.pattern)
- No key: Unselect by pattern. Was Minus. (select.unpattern)
- Alt+Left or Backspace: Back. Was Alt+Left. (go.back)
- Left or Alt+Up: Up one folder. Was Left or Backspace or Alt+Up. (panel.up)
- Alt+Period or ` or ^: Show hidden files. Was Alt+Period. (view.hidden)
- Ctrl+F3 or Alt+N: Sort by name. Was Ctrl+F3. (view.sort-name)
- Ctrl+F5 or Alt+T: Sort by modified. Was Ctrl+F5. (view.sort-modified)
- Ctrl+E: Shell here. No key before. (file.shell-here)
- Ctrl+Left or Ctrl+O: This folder to other panel. Was Ctrl+Left. (panel.this-in-other)

## Held back

These keys of the source are two keys in a row, which diroxide does not use: a key here is one key with its modifiers. The command each would run is reached by its own key, the menus or the palette.

- Ctrl+X Ctrl+X: Start a program.
- Ctrl+X S: Make a symbolic link.
- Ctrl+X Ctrl+S: Change a link's target.
- Ctrl+X C: Change permissions.
- Ctrl+X O: Change the owner, with alpha.7.
- Ctrl+X L: The command log, the job history here.
- Ctrl+X N: Newest files.
- Ctrl+L 1: The first layout.
- Ctrl+L 2: The second layout.
- Ctrl+L Ctrl+L: Center the row, which means nothing by ear.
