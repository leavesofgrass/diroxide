# Keyboard: the Total Commander preset

This page is generated by `cargo xtask keyboard` from `crates/diroxide-app/keys/presets/total-commander.toml`. Do not edit it by hand; change the preset file instead.

For people who know Total Commander's keys: the Norton row, Shift+F6 to rename, Alt with the function keys for archives.

Choose it in the Keys list (its first row, Choose a preset), with Key presets in the palette or in the Tools menu's Keys submenu, or from a shell with `diro keys preset total-commander`. Your own keys in `keymap.toml` stay on top of it, and every key it does not list is the one on [the keyboard page](keyboard.md). Each line below gives the key first, then the command, the key it replaces, and the command's id.

Single letters still jump to names with this preset.

Its keys come from a third-party list of Total Commander's shortcuts and forum pages, read for the project's research; Total Commander's own keyboard help page was not read.
