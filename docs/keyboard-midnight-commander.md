# Keyboard: the Midnight Commander preset

This page is generated by `cargo xtask keyboard` from `crates/diroxide-app/keys/presets/midnight-commander.toml`. Do not edit it by hand; change the preset file instead.

For people who know Midnight Commander's keys: the Norton row, with its Alt keys for history and paths.

Choose it in the Keys list (its first row, Choose a preset), with Key presets in the palette or in the Tools menu's Keys submenu, or from a shell with `diro keys preset midnight-commander`. Your own keys in `keymap.toml` stay on top of it, and every key it does not list is the one on [the keyboard page](keyboard.md). Each line below gives the key first, then the command, the key it replaces, and the command's id.

Single letters still jump to names with this preset.

Its keys come from Midnight Commander's manual, version 4.8.33, and its keymap file, read for the project's research.

## In a terminal

### In a panel

- \ or Minus: Unselect by pattern. Was Minus. (select.unpattern)
- Alt+Left or Alt+Y: Back. Was Alt+Left. (go.back)
- Alt+Right or Alt+U: Forward. Was Alt+Right. (go.forward)
- Alt+Shift+H: Folder history. No key before. (go.history)
- Ctrl+L or Alt+D or Alt+C: Go to a path. Was Ctrl+L or Alt+D. (go.path)
- Ctrl+Left or Alt+I: This folder to other panel. Was Ctrl+Left. (panel.this-in-other)
- Ctrl+F or Alt+?: Find files. Was Ctrl+F. (search.find)

## In the GUI

- F10 or Ctrl+Q: Quit. Was Ctrl+Q. (app.quit)

### In a panel

- Ctrl+B or Alt+B or Ctrl+\: Bookmarks. Was Ctrl+B or Alt+B. (go.bookmarks)

- Alt+Right or Alt+U: Forward. Was Alt+Right. (go.forward)
- Alt+Shift+H: Folder history. No key before. (go.history)

- Ctrl+F or Alt+?: Find files. Was Ctrl+F. (search.find)

## Held back

These keys of the source are two keys in a row, which diroxide does not use: a key here is one key with its modifiers. The command each would run is reached by its own key, the menus or the palette.

- Ctrl+X C: Change permissions, and the owner in its dialog.
- Ctrl+X S: Make a symbolic link.
- Ctrl+X Ctrl+S: Change a link's target.
- Ctrl+X L: Make a hard link.
- Ctrl+X I: Details.
- Ctrl+X Q: Quick view.
- Ctrl+X D: Compare folders, select the differences.
- Ctrl+X Ctrl+D: Compare files.
- Ctrl+X H: Add a bookmark.
- Ctrl+X J: Job history.
- Ctrl+X !: External panelize, with a later alpha.
- Ctrl+X T: Paste the marked names into the run prompt.
- Ctrl+X P: Paste the other panel's names into the run prompt.
